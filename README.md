# E-iching App Store support pages

Static English support and privacy pages for E-iching iOS 1.0. The public repository contains only these pages and their delivery metadata. The iOS source, App Review contact phone, and private reading data are not part of this site.

Pages: `index.html`, `support.html`, `privacy.html`.

Owner: eli. App: `6815041584`. Release purpose: provide a durable HTTPS Support URL and Privacy Policy URL for App Store Connect.

To verify a release, check the source commit, GitHub Pages build status, HTTPS responses for both pages, visible page text in a browser, and the URLs saved in App Store Connect. A future change to data practices requires a policy review before publishing.
